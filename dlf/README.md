# 国际象棋应用

这是一个基于HTML/CSS/JavaScript的国际象棋应用程序，提供人机对战功能。

## 功能特点

- 完整的国际象棋规则
  - 所有标准棋子移动
  - 王车易位（短易位和长易位）
  - 过路兵吃子
  - 兵的升变
  - 将军和将死检测
  - 逼和（无子可动）检测
  - 50步规则
- 计时功能（每方10分钟）
- 电脑AI玩家（基于Minimax算法和Alpha-Beta剪枝）
- 响应式界面设计，适配移动设备

## 如何使用

1. 直接在浏览器中打开`index.html`文件
2. 白方（底部）为人类玩家，黑方（顶部）为电脑
3. 点击您的棋子，然后点击目标位置进行移动
4. 如果兵到达对方底线，将显示升变对话框选择要升变成的棋子
5. 使用"新游戏"按钮可以重新开始游戏
6. 使用"撤销"按钮可以撤销上一步移动

## 技术实现

- **界面**：HTML5 + CSS3
- **游戏逻辑**：纯JavaScript实现
- **AI引擎**：基于Minimax算法和Alpha-Beta剪枝的电脑玩家

## 难度级别

电脑AI有三个难度级别，可以通过修改`js/app.js`中的以下代码行来更改：

```javascript
const chessAI = new ChessAI(chess, 'medium'); // 可选: 'easy', 'medium', 'hard'
```
