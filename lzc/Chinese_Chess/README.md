# 中国象棋游戏

这是一个使用HTML、CSS和JavaScript开发的简单中国象棋游戏，包含计分板、计时器和AI对手功能。

## 功能特点

- 完整的中国象棋规则
- 可视化的棋盘和棋子
- 有效移动提示
- 计时器功能
- 计分板记录胜负
- 简单AI对手（随机移动策略，但会优先吃子）
- 响应式设计

## 如何使用

1. 打开`index.html`文件在浏览器中运行游戏
2. 点击"开始游戏"按钮开始新游戏
3. 你控制红方棋子，AI控制黑方棋子
4. 点击你的棋子选中它，有效移动位置会显示绿色提示
5. 点击绿色提示处移动棋子
6. 点击"重新开始"按钮可以随时重置棋局

## 游戏规则简介

- **车（车/俥）**：可以横向或纵向移动任意距离，不能越过其他棋子
- **马（马/傌）**：走"日"字，即向前/后/左/右走一步，再斜着走一步，马腿被其他棋子占据时不能移动
- **相/象（相/象）**：走"田"字，即斜着走两步，不能过河，象眼被占据时不能移动
- **士（士/仕）**：走斜线一步，只能在九宫格内移动
- **将/帅（将/帅）**：走直线一步，只能在九宫格内移动，将帅不能直接对面
- **炮（炮/砲）**：移动时同车，但吃子时需要跳过一个棋子
- **兵/卒（兵/卒）**：只能向前移动一步，过河后可以向左右移动一步
